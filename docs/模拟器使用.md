# 模拟器使用

不接任何硬件，在 Mac 上跑整套设备：窗口里是 7.5 寸墨水屏，键盘当 3 个按键，手机可以扫屏幕上的二维码打开家长网页。
跑的是和真机同一份业务代码（`firmware/lib/core/`），只把屏幕、按键、flash、WiFi 换成了电脑上的实现。

## 一、第一次准备（只做一次）

```sh
brew install sdl2                                   # 窗口
python3 -m pip install pillow                       # 生成字库用（已装可跳过）
python3 -m venv ~/.platformio/penv                  # PlatformIO 装在独立环境里
~/.platformio/penv/bin/pip install platformio
```

字库、图标已经提交在 `firmware/data/`，不用重新生成。只有改了界面文字或图标时才需要：

```sh
python3 tools/build_assets.py                       # 在项目根目录运行；首次会下载字体源文件（约 20MB）
```

## 二、编译并打开

```sh
cd firmware
~/.platformio/penv/bin/pio run -e sim               # 编译，几秒钟
.pio/build/sim/program                              # 打开模拟器窗口
```

- 第一次运行时 macOS 可能弹窗问「是否允许接受传入网络连接」，选**允许**，手机才能访问家长网页。
- 改了 `firmware/platformio.ini` 之后，PlatformIO 会清空所有编译产物，要重新 `pio run -e sim`。

常用参数：

| 参数 | 作用 |
|---|---|
| `--reset` | 清空状态，像新设备一样从头开始 |
| `--start "2026-10-16 17:30"` | 把模拟器时间设成指定的北京时间 |
| `--port 8090` | 家长网页的端口（默认 8090；本机 8080 被 Docker 占用） |

状态（任务、星星、勾选、屏上画面）存在 `firmware/.sim/state/`，相当于设备的 flash，关掉再开会接着用。

## 三、怎么操作

| 按键 | 作用 |
|---|---|
| ↑ / ↓ | 移动光标（到头会绕回） |
| 回车 或 空格 | 确认：勾选 / 取消 |
| 按住回车 3 秒 | 进入家长设置（屏幕出现二维码） |
| T | 时间 +1 小时 |
| N | 跳到下次换日（默认凌晨 4 点）前 10 秒，看换日效果 |
| B | 电量 -10%（下次唤醒时生效，低于 15% 显示「电量低」） |
| W | 切换「有 / 没有 WiFi」，没有 WiFi 时长按会进配网页 |
| P | 模拟断电重启 |
| Esc | 退出 |

和真机一致的行为：

- 30 秒不按键就深睡，顶部状态栏显示「深睡中」；按任意键唤醒，**唤醒的那一下只亮光标，不会勾选**。
- 刷新有真实耗时：全刷 1.2 秒、局刷 0.45 秒（取自 GxEPD2 驱动源码）。刚局刷过的区域会闪一下红框（只在模拟器里有）。
- 每 20 次局刷自动插一次全刷；每天换日也全刷一次。
- 全部任务勾完：显示庆祝页，4 秒后回主界面。
- 顶部状态栏的「控制器错误」应该一直不出现；出现说明固件有刷屏 bug。

## 四、家长网页（用手机试）

1. 在模拟器里按住回车 3 秒，屏幕出现二维码和地址（例如 `http://192.168.x.x:8090`）。
2. 手机连**和 Mac 同一个 WiFi**，扫二维码打开；或者在 Mac 浏览器打开 http://localhost:8090 。
3. 可以改今天 / 明天的任务、每周模板、设休息日、加减星星、改换日时间。
4. 点「完成」或在模拟器里按一下回车，退出设置，屏幕刷新成新内容。
5. 10 分钟没有操作会自动退出；设备睡着时网页会提示先长按确认键。

## 五、自动化脚本（不开窗口）

用虚拟时间几秒跑完一周的流程，每一步截图，并核对「屏上实际显示 = 固件以为的画面」：

```sh
cd firmware
.pio/build/sim/program --script test/sim/full_week.txt --out .sim/shots --start "2026-10-16 17:30" --state .sim/state-script
```

- 截图在 `firmware/.sim/shots/`，最后一行打印全刷 / 局刷次数、控制器错误数、断言失败数；有失败时程序返回非 0。
- 加 `--state .sim/state-script` 是为了不覆盖你手动玩的进度（脚本模式每次都会清空状态目录）。
- 脚本命令：`key up|down|ok`、`hold ok 3.5`、`wait 31`、`jump 2026-10-17 03:59`、`shot 名字`、`http PUT /api/... {json}`、`battery 10`、`wifi off`、`power-cycle`、`expect view|done|stars|panel|sleeping|awake ...`。写法参考 `test/sim/full_week.txt`。

单元测试：

```sh
cd firmware && ~/.platformio/penv/bin/pio test -e test
```

## 六、Wokwi（可选，验证真机固件）

模拟器跑的是业务代码；Wokwi 跑的是真机固件（ESP32-S3 + GxEPD2 真驱动）。步骤见 `firmware/README.md` 的「Wokwi 仿真」一节。
注意：Wokwi 免费版每次连接最多 5 分钟；它不模拟 ESP32-S3 的真深睡（进深睡会直接重启），按键唤醒只能在本模拟器里看。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 启动时打印「HTTP 端口 xxxx 打不开」 | 端口被占用，换一个：`--port 8091` |
| 手机扫码打不开 | 手机和 Mac 不在同一个 WiFi；或 macOS 防火墙拦了，系统设置 → 网络 → 防火墙里允许 `program` |
| 屏幕上出现方框字 | 字库里没有这个字（GB2312 以外）；网页提交时会被拒绝并提示是哪个字 |
| `.pio/build/sim/program` 不存在 | 还没编译，或改过 `platformio.ini` 被清掉了，重新 `pio run -e sim` |
