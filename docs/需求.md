> 状态：已定稿 v1（2026-10-16）。琼哥逐项确认过；标「默认值」的是我按经验定的，琼哥可推翻。
> 实际界面见 [screens/](screens/)（模拟器截图，和真机画面一致）；早期草图 [mockup.html](mockup.html) 已过时。硬件见 [hardware.md](hardware.md)，模拟验证结论见 [模拟验证.md](模拟验证.md)。

## 一句话
放在孩子书桌上的 7.5 寸墨水屏相框：每天自动列出放学后的学习任务，孩子用 3 个实体按键自己打勾，全部完成得一颗星；家长用手机网页维护任务模板。

## 用户
- **孩子**：6–8 岁，认识一部分字 → **图标 + 大号中文**，主字号约 32–36px，一屏最多 6 条任务。
- **家长**：手机浏览器编辑，不装 App、不需要服务器。

## 已定决策

| # | 问题 | 结论 | 理由 |
|---|---|---|---|
| 1 | 屏幕 | 7.5" 黑白 800×480，横放，支持快速局部刷新 | 打勾要即时反馈，三色/彩色屏只能全刷，一次十几秒以上；黑白屏局刷约 0.45s |
| 2 | 孩子怎么打勾 | 3 个实体按键：上 / 下 / 确认 | 琼哥定。触摸方案的 M5PaperS3 已在多个渠道标停产，也不再考虑 |
| 3 | 家长怎么改任务 | 设备自带网页，同一 WiFi 下手机打开 | 不用服务器和 App；代价是出门在外改不了 |
| 4 | 任务类型 | 放学后的学习任务；**按星期固定模板 + 当天可增删**；周末另一套模板 | 家长日常基本不用动，有特殊作业时临时加一条 |
| 5 | 供电 | 内置锂电池 + USB-C 充电，平时深度睡眠 | 可以随手拿走；墨水屏断电也保留画面 |
| 6 | 激励 | 星星 + 连续天数 | 对 6–8 岁够用，实现简单 |
| 7 | 显示内容 | 任务 + 日期星期 + 今日进度（+ 星星、连续天数、本周星星） | 天气、家长留言放到 v2 |
| 8 | 硬件形态 | 散件 DIY，**现成相框改装**做外壳 | 琼哥定。型号见 hardware.md |
| 9 | 编辑时怎么唤醒 | 长按确认键 3 秒进入编辑模式，屏幕显示网址和二维码，10 分钟无操作自动退出 | 最省电。WiFi 常开的话续航会从按月算降到按周算 |

## 功能规格（v1）

### 1. 孩子端：屏幕 + 按键
- **主界面**（见截图）：左侧任务列表（勾选框 + 图标 + 任务名；已完成的整行变灰，不用删除线，免得把「口」划成「日」），右侧完成进度、星星总数、连续天数、本周 7 天星星。顶部日期星期，右上角电量。
- **按键**：
  - 上 / 下：移动光标（光标行反色显示）。
  - 确认（短按）：勾选或取消当前任务。**默认值：允许取消**，防止按错；家长能在网页上看到最终状态。
  - 确认（长按 3 秒）：进入家长编辑模式。
- **睡眠后第一次按键只唤醒、显示光标，不执行操作**，避免一碰就误勾。光标默认落在第一条未完成的任务上。
- 无操作 **30 秒**（默认值）后隐藏光标、进入深度睡眠，画面保留。
- **全部完成**：全屏刷新显示庆祝页（大星星 +「今天的任务全部完成！」+ 连续天数），蜂鸣器放一段短旋律（约 2 秒）。之后回到主界面，所有条目显示已勾。
- **当天没有任务 / 家长标了休息日**：显示休息页。
- 电量低于 15% 时右上角显示低电量图标。

### 2. 每日逻辑
- **每天 04:00 重置**（默认值）：按当天星期取模板，合并家长对当天的增删，生成今日清单；全屏刷新一次（同时清残影）；联网 NTP 校时。
- **星星**：某天任务全部完成 → +1 星。
- **连续天数**：每个有任务的日子都全部完成才 +1；有任务但没完成 → 归零；休息日和没有任务的日子跳过，不加也不断。周末模板的日子同样计入。
- 局部刷新每累计 20 次插一次全刷（默认值），防残影。

### 3. 家长端：手机网页
- **进入方式**：长按确认 3 秒 → 设备连家里 WiFi、启动网页 → 屏幕显示二维码、`http://todo.local` 和 IP（部分安卓手机不支持 `.local`，所以 IP 也要显示）。10 分钟无操作或在网页上点「完成」即退出、回到主界面。
- **首次配网**：没有 WiFi 配置或连不上时，设备开热点 `EinkTodo-Setup`，手机连上自动弹出配网页（captive portal）。
- **页面功能**：
  1. **星期模板**：周一到周日各一份清单，每条 = 任务名（≤8 个汉字，默认值）+ 图标（从预置图标库选）。可拖动排序。
  2. **今天 / 明天**：在模板基础上临时增删任务；把某天标为休息日。
  3. **概览**：今天的完成情况、星星总数、连续天数、最近 14 天记录。
  4. **家长调整**：手动加减星星（奖励或纠错）。
  5. **设置**：WiFi、重置时间、蜂鸣器开关。
- 网页文字中文，手机竖屏优先。

### 4. 预置图标（约 20 个，1-bit 48×48）
语文、数学、英语、口算、阅读、背诵、听写、练字、英语听读、练琴、画画、跳绳、运动、整理书包、预习、订正、手工、科学、检查作业、通用（星形）。家长可以不选图标，用通用图标。

## v1 不做（v2 候选）
天气、家长留言、出门在外远程修改（需要云端）、网页 OTA 升级固件、星星兑换奖励、多孩子。

## 验收标准
1. 按一下打勾，到屏幕显示勾选，**1 秒内**完成（不含唤醒的第一次按键）。
2. 连续打勾 50 次没有明显残影；每日全刷后画面干净。
3. 04:00 重置后，任务与当天星期模板加临时增删的结果一致；周末使用周末模板。
4. 星星和连续天数按上面的规则计算正确（含休息日跳过、未完成归零）。
5. 家长从长按到手机打开网页 **≤ 30 秒**（WiFi 正常时）。
6. 网页上输入任意常用汉字（GB2312 范围），屏幕都能正确显示。
7. 断电、没电重启后，模板、星星、连续天数、今天的勾选状态都不丢。
8. 续航：满电正常使用（每天约 30 次按键、每周编辑 2 次）**至少 4 周**。这是目标值，样机实测后修正。

## 技术要点
- **中文字库**：任务是家长在网页上随便输入的，没法只取模用到的字 → 预生成 **GB2312 全集点阵字库**（7541 字，含补充的 `·▼`），24px 629KB + 32px 1014KB；48px 只含界面固定文案（自动从源码收集）。字体：Noto Sans SC Bold（SIL OFL，可商用）。生成脚本 `tools/build_assets.py`。网页提交的字不在字库里会被拒绝并提示是哪个字。
- **时间**：板子没有外置 RTC，深度睡眠期间靠芯片内部时钟，可能有漂移（幅度需实测）。每天 04:00 联网校时兜底；连不上网也照常运行。漂移太大的话加一块 DS3231（但 XIAO 的引脚已经用满，需要换方案，见 hardware.md）。
- **数据**：LittleFS 上存 JSON（模板、按日期的覆盖、今日状态、星星、连续天数、14 天历史）。写入要做原子替换（先写临时文件再改名），防止掉电写坏。
- **固件栈**（计划）：PlatformIO + Arduino-ESP32 + GxEPD2（屏幕）+ ArduinoJson + LittleFS + WebServer + mDNS + 二维码库。
- **墨水屏**：频繁局刷要定期全刷防残影；低于 0°C 刷新会变慢甚至失败，放室内问题不大。
