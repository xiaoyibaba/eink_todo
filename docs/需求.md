# 需求

> 状态：草稿（2026-10-16）。「待定」项定了就改成结论，并写清理由。

## 基础需求（琼哥给的）
- 给孩子用的 todolist，显示在墨水屏上。
- 硬件：墨水屏 + ESP32 等开发板。

## 待定

| # | 问题 | 选项 | 影响 |
|---|---|---|---|
| 1 | 屏幕尺寸和颜色 | 黑白 / 三色（红或黄）；4.2" / 7.5" 等 | 三色屏一般不支持局部刷新、全刷很慢；黑白屏能局部刷新，打勾体验好 |
| 2 | 孩子怎么打勾 | 物理按键 / 不交互（只看，家长勾） | 决定要几个按键、外壳怎么开孔 |
| 3 | 家长怎么改任务 | ESP32 自带网页（局域网）/ 云端 + 手机页面 / 写死在固件里 | 决定要不要 `web/`、`server/` 目录 |
| 4 | 任务类型 | 每日固定清单（刷牙、作业…）/ 临时任务 / 两者都有 | 决定数据结构和每天几点重置 |
| 5 | 供电 | USB 常供电 / 电池 + 深度睡眠 | 电池方案要做功耗设计、唤醒逻辑 |
| 6 | 激励 | 无 / 星星、积分、连续天数 | — |
| 7 | 显示内容 | 只有任务 / 加日期、天气、完成进度 | 联网对时（NTP）、天气接口 |

## 技术要点（先记下）
- **中文显示要字库**：ESP32 存不下完整中文字库，需要按实际用到的字取模（`tools/` 放脚本），或用现成的 GB2312 子集字体。
- 墨水屏断电后画面仍保留，适合"不常变"的内容；频繁局部刷新要定期全刷，防止残影。
